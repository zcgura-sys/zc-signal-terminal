# SIGNAL · Workers 版（前后端分离 · Git 自动部署）

SIGNAL **v2.34.2** 的 Cloudflare **Workers** 形态。v2.23 起**前后端分离**：
`_worker.js` 只含后端；前端页面放在 **`public/` 目录**（`public/index.html`、`public/admin.html`）。

> ⚠️ **前端必须放在 `public/` 子目录，不要放到仓库根目录。** 原因：静态资源目录里只要
> 出现名为 `_worker.js` 的文件，Cloudflare 会直接拒绝部署并报错
> `✘ Uploading a Pages _worker.js file as an asset.`（防止后端源码被当静态资源公开）。
> 把静态资源目录限定为 `public/`，`_worker.js` 天然在其范围之外，问题从根上消失，
> 也不再依赖 `.assetsignore` 这种隐藏文件（少传一个文件就会部署失败）。

> **v2.34.2（前端 · 四个 bug 修复）**：
> **一、联网开关不再「假装联网」**。旧版把「要不要联网」交给模型自己判断，问「今天几月几号」这类它自以为知道的问题时，模型直接回 `NO_WEB`，一个请求都没发 —— 看起来就是「开了联网却没联网」。现在开关打开就必须真查：提示词要求**第 1 轮先调用 `web_search`**（日期、时间、新闻、价格、版本、政策这类尤其必须先搜再答）；模型这一轮**没调用任何工具**（包括它回 `NO_WEB`、或接口悄悄忽略了 `tools` 参数）一律走兜底检索，由前端代搜代读；兜底方案也不再依赖模型的 `need` 字段，没有检索词就用**用户最后一句**当检索词 —— 也就是说，开着联网就不可能「一次都没查」。因为任何模型都无法提供真实日期，系统提示词里还**补上了当前日期与时间**（含星期、时区），并写明「涉及今天 / 现在 / 最近的问题一律以这个时间为准，不要凭记忆推断」。
> **二、聊天模式开的「深度思考」不会再串到代码模式**。旧版思考强度只有**一份全局设置**，在聊天模式打开后切到代码模式照样开着。现在按模式**各存一份**（`deep_on_chat` / `deep_level_chat` / `deep_on_code` / `deep_level_code`），切模式时自动换过去，两份都进云同步；升级首次启动会把旧值**同时**写给两份（升级前是什么样，升级后两个模式就是什么样），之后各改各的。
> **三、思考一致性守卫不再「反向纠错」**。旧版的语言要求只认「思考……用中文」这一种语序，而且要求否定词写在「思考」之后才算反向 —— 于是「不许用中文思考」「不要用英文思考」根本没被识别；更糟的是这类句子被当成普通禁区句，「中文」被抽成思考禁区词，模型一在思考里复述「我不用中文」就被判违规，接着纠偏提示又硬写「思考请使用中文」，**正好和用户的要求相反**。现在：
> ① **语言要求单独解析**，两种语序都认（「思考过程请用中文」「不许用中文思考」），否定词在语言词之前或之后都算（「思考时不要用英文」= 要求中文），也支持英文写法；
> ② **整句规则不再被当禁区词** —— 「不许用中文思考」这类「否定 + 思考」的整句不会被抽成词，模型在思考里复述规则不再被判违规；填在「思考禁区」里的整句规则同样过滤（只填禁区词的项目不受影响）；
> ③ **引用 / 复述规则一律按「存疑」处理**，交给语义核对，不直接判违规；
> ④ **纠偏提示按用户的方向说** —— 要求英文思考时不会再写「请使用中文」。
> **四、项目里的对话不再漏到项目外**。病根是好几条路径都会造出「属于项目却记在项目外」的对话：在项目里**切换模式**（聊天 / 代码）时按全局找空白对话、点「新对话」、或点到自动新建的空白对话。现在：切模式只会在**当前项目内**找 / 建空白对话；「空白对话落在项目外就归回来」在切换对话、点「新对话」、以及任何一次点击 / 聚焦 / 回到页面时兜住；启动时一次性迁移旧数据里漏在项目外的空白对话（只做一次）。**已有内容的对话绝不会因为切换而被改归属**；你手动「移出项目」的空白对话也记了标记，不会被自动捡回去（宁可在项目外显示「不知道属于哪里」，也不擅自把对话挪进项目）。
> **五、输入框写长了不再把主页内容顶出屏幕**。首页用「整体垂直居中」排版，输入框多行变高（最多 220px）后整组超过可用高度，flex 会把溢出部分平均推到上下两侧 —— 顶部图标 / 标题被夹在顶栏下面看不见，被盖住的按钮自然也点不到。现在一旦放不下就给首页加 `.tight`：改为**从顶部排 + 欢迎页自己滚动**，输入框始终完整贴在底部；空间够时保持原来的居中观感。输入框每次撑高和视口变化（键盘升降 / 旋转 / 窗口缩放）都会重算。另外把输入框工具栏浮层的层级从 `60` 提到 `72`（高于手机侧栏 / Agent 抽屉 `70`），在项目模式或抽屉打开时点「模型」「思考强度」不会再像没反应。
> **诚实说明**：这一版的浏览器交互回归**没能在本机跑**（容器里 Chromium 启动后开不了页面），上半部分的纯逻辑与静态契约 23 项全部通过；`test_v34_2_fixes.mjs` 里的浏览器用例在有 Playwright + Chromium 的机器上会自动执行（`npm test` 已串上）。项目里的**旧对话**（v2.34.2 之前就归属不明的）不会被自动搬进项目 —— 自动迁移只处理「空白且未归档」的对话，避免擅自改变已有对话的归属。
> **v2.34.1（前端 + Worker · 思考一致性守卫修复 / 聊天联网）**：
> **一、修复「设了 10 次，模型第二次思考违规却没被纠正」**。根因：守卫判断一段思考是不是违规时，先用一个很宽的「复述规则」白名单放行——只要句子里出现「指令 / 规则 / 不能 / 禁止」之类的字眼就当成「模型在遵守规则」。可模型第二次常这样写：「虽然指令说不能谈价格，但用户在问价格，那我算一下……」——既复述了规则、又真的在谈价格，结果被白名单放过。现在改成**逐个分句判断**：「按指令不谈 X」「我不会涉及 X」这类遵守型分句放行；「虽然……但……」「还是先想想 X」「既然问了就算一下 X」这类先复述再违规的分句拦截；介于两者之间的「存疑」句交给语义核对。同时：① 新增**「自动」模式**（默认）：本地规则先判断，第一次命中后自动升级成语义核对，抓「换了个说法」的违规；② 重试时把**已被判违规的词和说法列成清单**一并投喂（禁区清单），第 2 次起会写明「已被纠正了 N 次」；③ 项目设置里可选重试次数 2 / 3 / 5 / 8 / 10；④ 新增**「试一试规则」**测试框：粘一段思考进去，立刻看会不会被拦、为什么；⑤ 回复上的「已自动纠正 N 次」可以点开，逐次看当时哪句违规、违反了哪条；⑥ 只填了「思考禁区」词、没写别的指令的项目也能用。仍然**不执行**涉及未成年 / 年龄话题的压制，也不执行「忽略安全 / 道德」类指令（这类条目会被忽略并在项目里提示）。Agent 模式同样适用，已加回归测试。
> **二、聊天模式新增「联网」开关（一个按钮，三个能力）**。输入框工具栏里的「联网」（地球图标，开启时陶土橙底色，和「深度思考 / 生图」同一套样式）。打开后，每次发送先跑一个**检索阶段**：模型自己决定要不要联网，并用三个工具查资料——`web_search`（搜索）、`web_read`（读网页正文，长网页分段读）、`web_extract`（抓取链接 / 表格 / 标题大纲 / 元信息 / 指定 CSS 选择器的元素）；最多 5 轮、8 次调用。查到的资料带编号塞进系统提示词，然后走原来的正常流式回答（深度思考、守卫、停止、重新生成都照旧）。回复上方多一行「已搜索网络 · 阅读 N 个网页 · M 个来源」（和思考块同一风格，进行中有流光和转圈，点开能看每一步和来源），回答里的 [1] [2] 变成可点的来源角标。闲聊 / 纯创作 / 纯计算模型会直接判定「不需要联网」，不搜索、不多花时间。代码模式里不显示这个按钮（Agent 自带 web_fetch / web_search）。
> Worker 侧配合：网页读取新增 `html:true`（返回网页原文给前端在浏览器里解析，不执行脚本）、按网页声明的编码解码（GBK / Big5 等不再乱码）、返回网页标题；免费搜索在 DuckDuckGo 没结果时自动再试 Bing。

> **v2.34.0（前端 + Worker · 沙箱不丢 / Agent 动效 / 顶栏 ⋯ / 分支归档整理 / 思考一致性守卫）**：
> **一、Agent 干到一半沙箱被重置（根因 + 四层对策）**。根因有二：① E2B 默认「到期即 kill」（`onTimeout` 默认 kill），kill 会销毁文件系统和进程且不可恢复——手机锁屏 / 切后台 / 断网超过存活时长（默认 30 分钟），前端心跳停了，沙箱到点被杀，下一次请求只能新建一个空沙箱；② 不暂停的连续运行有平台上限（Hobby 1 小时 / Pro 24 小时），长任务跑到点同样被收回。对策：**① 到期改暂停**——创建沙箱时带 `autoPause` + `autoResume`，到期保存文件系统和内存而不是销毁（暂停的沙箱无限期保留）；任何请求发现是暂停态，先 `connect` 唤醒（约 1 秒），不新建；遇到 409（正在暂停 / 恢复中）等一下再试，GET 对暂停沙箱返回 404 的接口版本也能唤醒；只有 connect 也说不存在才判定「真没了」。**② 连续运行快到上限时主动「暂停 → 恢复」**一次（计时清零，进程与内存保留），默认每 50 分钟。**③ 保活**——运行期间每 60 秒心跳 + 页面回到前台立刻探活 + 屏幕常亮（Wake Lock，设置里可关，存储键 `zc_gura_sbx_wakelock`）。**④ 兜底：写入日志 + 自动恢复**——真的被重建时，前端把本次任务里模型写过的文件（单个 ≤400KB、合计 ≤6MB）按顺序补写回新沙箱，并用一条系统提示告诉模型「沙箱已重建、哪些文件已恢复、哪些需要核对」，让它接着干而不是从头来。新增变量（都不用配也能用）：`E2B_AUTO_PAUSE`（默认开；填 `0` 退回旧的到期销毁）、`E2B_MAX_RUN_SECONDS`（默认 `3000`，`0` 关闭，上限 `82800`；Pro 账号可调大）。`E2B_TIMEOUT_SECONDS` 的默认值是 `1800`（旧文档写的 `300` 是过期说明）。`/__zc_sandbox__/status` 与 `ping` 会如实返回当前是「到期暂停」还是「到期销毁」、是否刚从暂停中唤醒。
> **二、Agent 动效更接近 Claude**（图标是 ZC-Agent 自己的信标，不是 Claude 的星芒）：① **思考块有完整生命周期**——思考中「正在思考…（N 秒）」+ 文字流光，开始输出正文 / 调用工具就变成「已思考 N 秒」、流光停止、自动折叠（旧版 Agent 里已经思考完的回合还写着「正在思考…」，也没有时长；你手动展开过的不会被自动收回）；② 思考内容流式时只露出最近几行，顶部渐隐，不再撑开一大块；③ 运行中的状态行像 Claude Code：「盘算中… 12s · ↓ 1.2k tokens」，流式期间按字数估算，每步结束后用接口给的真实用量校正；④ 正文流式输出时新到的文字有淡入（按到达时间错开），尊重系统「减少动态效果」，超长文本自动停用。
> **三、项目模式下右上角 ⋯ 被遮挡**：病根是模型按钮、项目标签都「内容多宽就多宽」，而右侧图标按钮可被压缩——选中项目后顶栏多一个项目标签，模型名稍长整条顶栏就比屏幕宽，手机 360px 宽时 ⋯ 被挤到屏外（x=412），页面还能横向拖动。现在图标按钮不再被压扁 / 挤出，模型按钮与项目标签可收缩并显示省略号。（说明：这一条没收到你的截图，是按症状在 360 / 390 / 412 宽度下复现并修复的；若你的机型仍遮挡，发一张截图即可。）
> **四、记忆里分支和归档太乱的整理方案**：① **折叠**——「编辑前」备份与分支不再和主对话平铺在一起，而是收在来源对话下面（行首小分叉标记，点开 / 收起），列表只剩真正的对话；搜索 / 标签筛选时仍平铺，保证搜得到；② **分清两种**——分支（你主动分叉、或在备份里接着聊过的）与备份（编辑重发前自动留的）用不同标签；③ **自动去重与封顶**——内容相同的备份只留一份，每个对话最多保留 4 个备份（有用过的会被「升格」成分支，不会被清掉）；④ **一次性迁移**——首次启动自动把旧数据按上面的规则整理（只做一次，已删除的会写墓碑，云同步时不会又同步回来）；⑤ **手动整理**——顶栏 ⋯ →「整理分支与归档…（N）」随时再整理一次；项目里的对话计数也不再把嵌套的分支重复计入。
> **五、项目「指令只读一次」+ 思考一致性守卫**：项目设置里新增「思考一致性守卫」。你在指令里写「思考时不要提及……」「思考过程请用中文」（或直接填「思考禁区」），模型一旦在**思考过程**里违反，就**中途中断这次生成、丢弃这段思考，把项目指令全文再投喂一遍**（system 末尾追加「指令纠偏 · 第 N / M 次」+ 指令全文，并说明违反了哪一条），让模型重新思考；最多重试 3 / 5 / 8 / 10 次（默认 5），用满后放行最后一次并在回复上标「已用满」，不会死循环；纠正过的回复上有小标记「已自动纠正 N 次」；纠偏发生后「指令只读一次」自动失效、下一轮完整重读。普通对话与 Agent 每一步的模型请求都校验。模式：「快速」（默认，关键词 / 语言规则，零额外请求）与「严格」（思考结束后再让模型当一次裁判，多 1 次请求）。**范围说明**：涉及「不要考虑未成年人 / 年龄 / 儿童安全」「忽略安全 / 道德 / 法律」这类内容的指令不在这个功能的范围内——不会被识别成规则、也不会被执行（项目编辑器里会显示「已忽略 N 条」）；你给的那个例子只是举例，我没有把它做成预置规则。
> **诚实说明（已知限制）**：沙箱恢复靠的是「写入日志」，所以**由 shell 命令生成的文件（`npm install` 的 `node_modules`、`git clone` 的内容、编译产物）无法逐个补写**，只能提示模型重新执行；日志只在内存里，刷新页面就没了；账号 / 接口版本不认暂停字段时（HTTP 400）自动退回到期销毁并在状态里标明，这种情况下只能靠保活和日志兜底；手机系统把整页杀掉时，浏览器里的 Agent 循环本身会停（沙箱在暂停里是安全的，回到页面再发「继续」即可），这一点服务端无法替代。token 数在流式期间是估算值。

> **v2.33.1（前端 · 项目模式修复）**：
> ① **Agent 回合「编辑并重新发送」不再掉回普通对话**：旧版 `applyEdit` 不管是不是 Agent 任务都走普通对话的 `run()`，所以 Agent 里改一句话重发，回答就没有工具、没有 Agent 模式了（与是否在项目里无关）。现在 Agent 回合编辑后仍交给 `Agent.run`，附件原样带上；Agent 模式被关掉时自动回到 Agent（和「重新生成」一致）；没选工作区 / 没配 API 时先预检拒绝，原对话不动，也不会白存一个「编辑前」备份。「新对话」同理，已一并验证。

> ⑤ **项目指令「完整读取」+「指令只读一次」开关**：指令送给模型时用「开始 / 结束」标记框住并写明总字数，明确要求从头读到尾，不得因篇幅长（800 / 1000 / 2000 字等）只读一截。项目设置里新增开关「指令只读一次」（默认开）：模型在一段对话里读完指令并回答 / 开工后，之后每一轮（普通与 Agent 共用同一份记忆）system 里改成「已读过、已答应遵守，不要重读 / 复述 / 确认，接着上一轮继续」。分支、「编辑前」备份会带着已读记录；改了指令、换了项目、或编辑 / 重新生成把那条已读回答截掉后，会重新读一次；每个项目、每段对话各算各的。
> **诚实说明**：接口是无状态的，指令原文必须每次随请求带上（真删掉模型就忘了），所以「不再读」靠措辞约束，不是靠把原文从请求里去掉；Token 用量与旧版持平。`user-scalable=no` 会让系统无障碍放大失效，这是按需求有意为之。

> **v2.30.4（前端 + Worker · Agent）**：① **云端 → 本地「拉回」提速并可见进度** —— 病根：旧版逐个文件串行调 `readchunk`，200 个文件 = 200+ 次沙箱往返，既慢又容易撞 `SEC_RATE` 限流（`CloudFS.api` 对 429 最多重试 4 次、退避叠加，能拖到十几分钟），而且整个过程只显示一行「正在从云端拉回 200 个文件…」、结束才刷新目录，看起来就像「一个文件也没拉回」。现在：Worker 新增 `readmany`（一次沙箱执行读回一批小文件，逐个带大小 + SHA-1，二进制安全）；前端 `AgentMix.pullList` 小文件成批、批与大文件 3 路并发、实时进度（卡片 / 工具栏「拉回」按钮显示 N/总数）、拉回中每 2.5 秒刷新文件树；带时间预算（模型申请拉回 150 秒、命令后自动拉回 60 秒），超时会停下并明确提示「还剩 N 个，再调用一次继续」（已拉回的有 `pushed` 记录，不会重复拉）；旧 Worker 没有 `readmany` 时自动回退逐个读取。单次文件数上限 200 → 500。② **Agent 任务对话不再因退出 / 刷新丢失** —— 旧版助手消息只在任务结束时才写入存档，任务中途退出网站，这一轮的步骤、思考、已输出文字全部丢失（只剩用户那条）。现在任务一开始就在存档里占一条助手消息（`meta.running`），每 3 秒 / 每一步 / 页面隐藏或关闭时更新，结束时写回同一条；重进时 `Sessions.recoverRunning` 把它收口成「已中断」：已完成的步骤、思考、已输出文字都保留，转圈的步骤标为已中断，并提示发「继续」接着做（任务快照本来就在）。新增 `test_pull_batch.js`（18 项）。

## 静态资源安全

静态资源目录是 `public/`，其中**凡是被纳入的文件都会公开可访问**（`https://站点/<路径>`）。
`public/.assetsignore` 用白名单反转写法，只放行两个页面：

```
*
!index.html
!admin.html
```

后端源码、`wrangler.jsonc`、`node_modules` 等都在 `public/` **之外**，
从设计上就不可能成为静态资源，不存在源码泄露风险。

> 以后新增可公开的静态文件（图片 / 字体 / 额外页面），在 `public/.assetsignore` 追加一行 `!文件名`。

## v2.15 安全防护层（默认开启，不配变量就能用）

| 能力 | 说明 |
|---|---|
| **敏感操作只在后端** | 所有密钥只存在于 Worker 运行时；`/__zc_sec__/selfcheck` 会主动拉自己的页面扫描，一旦发现密钥值出现在返回内容里立刻报警 |
| **防扫描挖洞** | 路径/参数特征库：目录穿越、SQLi/XSS 载荷、`.env`/`.git`/`wp-*`/`phpmyadmin` 等诱饵路径 → 命中即拒 + 记分 |
| **防爬虫** | `X-Robots-Tag: noindex…` + `robots.txt` 全站 Disallow + 缺少浏览器特征（无 `Accept-Language`/`Sec-Fetch-*`）的自动化请求拒绝 + 机器人 UA 库（Googlebot/Bytespider/curl/sqlmap/nuclei…） |
| **自动封禁** | 记分累计 ≥ 阈值 → 封禁 IP（KV 全局生效，内存兜底），可通过接口解封 |
| **分级限流** | 页面 120/分 · 普通接口 90/分 · 敏感接口（run/sandbox/ghterm/admin/auth）30/分，按 IP |
| **CSRF / 跨站防护** | 状态变更请求必须同源（`Sec-Fetch-Site` / `Origin` 校验） |
| **不泄露内部信息** | 统一错误响应（不透明拒绝）+ 异常兜底 + 错误信息密钥脱敏 + 安全响应头（HSTS / nosniff / X-Frame-Options / COOP / CORP / Referrer-Policy） |

### 可选安全变量（都建议按「密钥」类型添加）

| 变量 | 默认 | 作用 |
|---|---|---|
| `ZC_SEC_MODE` | `on` | `on` / `monitor`（只记录不拦）/ `off`（关闭） |
| `ZC_SEC_KEY` | 回退到 `ZC_ADMIN_TOKEN` | 自用脚本通行证：请求带 `x-zc-key: <值>` 即跳过全部拦截 |
| `ZC_SEC_BAN_SECONDS` | `86400` | 封禁时长（秒） |
| `ZC_SEC_STRIKE_LIMIT` | `3` | 记分到多少自动封禁 |
| `ZC_SEC_RATE_PAGE` / `_API` / `_SENS` | `120` / `90` / `30` | 每 IP 每分钟上限 |
| `ZC_SEC_ALLOW_UAS` | 空 | 额外放行的 UA 正则（谨慎） |

### 安全管理接口（需 `x-zc-key`，否则一律 404）

```
GET  /__zc_sec__/status              看当前模式、计数、封禁、密钥长度（不含值）
POST /__zc_sec__/unban   {"ip":"…"}  解封某个 IP
POST /__zc_sec__/selfcheck            安全自检（密钥泄漏 / 响应头 / 诱饵拦截 / robots）
```

## 在 Cloudflare 里接上（Git 自动部署）

1. 控制台 → **Workers 和 Pages** → **创建新项目**
2. 点 **Continue with GitHub** → 授权（建议选 **Only select repositories**，只给这一个仓库）
3. 选择本仓库
4. 构建设置：
   - **构建命令**：`npm install`
   - **部署命令**：`npx wrangler deploy`
5. 点 **Deploy** → 完成后地址是 `https://<worker名>.<账号子域>.workers.dev`

> 改代码后只需覆盖上传 `_worker.js`，Cloudflare 自动重新构建部署，**没有「再点一下部署」这一步**。
> ⚠️ 变量务必按「**密钥**」类型添加：明文「变量」在每次 Git 构建时会被 `wrangler.jsonc` 覆盖掉。

### 沙箱按账号隔离（安全修复）

云端沙箱的工作区由**服务端按登录账号派生**（`u` + sha256(账号 + 项目名)），不再信任客户端的 `x-zc-workspace`：

- GitHub 登录的账号为 `<login>@github`，邀请码登录为其账号邮箱，两者都会得到各自独立的 E2B 沙箱；
- 不同用户即使都使用项目名 `main` 也互相看不到对方的文件，无法通过伪造请求头或沙箱 ID 接管他人沙箱；
- 没有有效会话一律返回 401。单人自用且已关闭登录（`ZC_AUTH_DISABLED=1`）时，可显式设置 `ZC_SBX_ALLOW_ANON=1` 允许匿名使用；
- 回归测试：`node test_sandbox_isolation.mjs`。

### 审计 / 后台任务 / 审批按账号隔离（v2.25 安全修复）

修复前：`/__zc_audit__`、`/__zc_task__`、`/__zc_approval__` 三类记录存在全局 KV 键里，只校验「是否登录」，不区分账号 —— 任何登录用户都能在「审计与权限」面板里看到别人的后台任务标题 / 进度、别人的审计条目与审批详情，还能改写 / 取消别人的任务、批准别人的审批单、甚至一键清空所有人的审计日志。

修复后：

- 每条记录写入时标记服务端解析出来的 `owner`（登录会话邮箱，客户端无法伪造）；未登录 / `ZC_AUTH_DISABLED=1` 单人自用时为 `anon`；
- 查询、追加、清空、更新 / 取消任务、审批决定、持续策略撤销全部按 `owner` 过滤，跨账号操作一律 404（不暴露存在性）并写入一条 `denied` 审计；
- 沙箱 / GitHub 终端的审批闸门也只认当前账号自己的审批单（不再能用别人的批准单解锁）；
- 持久化按 owner 分组各留最近 N 条，别人的高频写入不会把自己的记录挤掉；
- 兼容取舍：启用登录之前产生的历史条目没有归属信息，一律按 `anon` 处理 —— 登录用户不再看到它们（宁可看不到，也不跨账号泄露）；关闭登录自用时照旧可见。

兼容与例外（如实说明）：GitHub 终端（`/__zc_ghterm__`）的工作区状态仍是单实例（一个 `GITHUB_TOKEN` = 一个终端仓库），多人使用同一部署时它会共享；如需多人各自独立，请告知，后续按账号拆分仓库。


## 云端沙箱：E2B（v2.14 主推，替代 Cloudflare Containers）

在 Cloudflare 加一个变量即可（按「密钥」类型）：

```
E2B_API_KEY = e2b_...        （必填，https://console.e2b.dev/?tab=keys）
```

可选调参（不填走默认）：`E2B_TEMPLATE_ID`（默认 `base`，Debian 12 + Node 20 + Python 3.11 + git + sudo）、`E2B_TIMEOUT_SECONDS`（默认 `1800`，上限 `3600`）、`E2B_ALLOW_INTERNET`（默认 `true`）、`E2B_AUTO_PAUSE`（默认开：到期**暂停**而不是销毁，文件与进程都保留；`0` 关闭）、`E2B_MAX_RUN_SECONDS`（默认 `3000`：连续运行满这么久主动「暂停→恢复」一次以避开平台的连续运行上限；`0` 关闭）。

沙箱特性：非 root 用户但 `sudo` 免密可用；工作区 `/workspace`（首次自动用 sudo 创建并改属主）；空闲超时后**自动暂停**（v2.34 起；账号不支持时退回销毁），按秒计费。

## 验证接口

```
GET  /__zc_health__              总览（版本 / KV / 沙箱 / 鉴权 / 安全模式）
GET  /__zc_auth__/status         登录配置
POST /__zc_sandbox__/debug       E2B 会话与持久层诊断
POST /__zc_sandbox__/upload      上传文件（原始字节流；&part=N 分片）
POST /__zc_sandbox__/assemble    拼装分片（{path, parts}）
POST /__zc_sandbox__/unpack      解压 .zip / .tar.gz / .tgz / .tar
POST /__zc_sec__/status          安全防护状态（需通行证）
```
